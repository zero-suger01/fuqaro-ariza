# e-Murojaat mobile

Expo + React Native fuqaro ilovasi. Mavjud `/api/public` kontraktlaridan foydalanadi.

```bash
cd mobile
npm install
cp .env.example .env
# .env ichida kompyuterning LAN IP manzilini yozing
npx expo start
```

Telefon va kompyuter bir Wi-Fi tarmog‘ida bo‘lishi kerak. Android emulator uchun odatda `http://10.0.2.2:8001`, iOS simulator uchun `http://127.0.0.1:8001` ishlatiladi.
